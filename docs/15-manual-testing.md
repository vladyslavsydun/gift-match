# Практична робота №15. Основи тестування програмного забезпечення

## Мета

Ознайомитися з основними видами та підходами до тестування програмного забезпечення.

## Хід роботи

### 1. Що необхідно перевіряти

| Область | Що перевіряємо | Звідки вимога |
|---|---|---|
| Додавання людини | правильні дані зберігаються, неправильні — ні | FR-1, FR-2 |
| Збереження | дані залишаються після перезавантаження | FR-13 |
| Редагування / видалення | змінюється/видаляється саме потрібний запис | FR-4, FR-5 |
| Пошук і сортування | правильні результати, регістр не важливий | FR-9, FR-10 |
| Підбір подарунків | ≤ 5, сортування, 0–100%, причини | FR-6, FR-7 |
| Маркетплейси | правильне посилання, лічильник | FR-8, FR-11 |
| Імпорт | неправильний файл не ламає список | FR-12, FR-14 |
| Безпека відображення | текст користувача показується як текст | FR-14 |

### 2–3. Позитивні та негативні сценарії

- **Позитивні** (правильні дані, очікуємо успіх): TC-01, TC-09, TC-10, TC-11, TC-12, TC-13, TC-14, TC-15, TC-16, TC-17, TC-20.
- **Негативні** (неправильні дані, очікуємо помилку): TC-02, TC-03, TC-04, TC-05, TC-06, TC-07, TC-08, TC-18, TC-19.

Для віку я використав **граничні значення**: 0 і 121 (одразу за межами 1–120) і дробове 25.5.

#### TC-01. Додавання людини з правильними даними
- **Опис:** перевірити, що людина з правильними даними додається у список.
- **Тестові дані:** Олена, 25, жіноча, дизайнер, хобі: малювання, фотографія.
- **Передумови:** застосунок відкрито, список порожній (DevTools → Application → Local Storage → очищено).
- **Кроки:**
  1. У поле «Ім'я» ввести `Олена`.
  2. У поле «Вік» ввести `25`.
  3. Обрати стать «жіноча».
  4. У «Професія» обрати `дизайнер`.
  5. Відмітити хобі `малювання` і `фотографія`.
  6. Натиснути «Додати».
- **Очікуваний результат:** у списку з'явилась картка «Олена, 25», лічильник «Список людей (1)», форма очищена.
- **Фактичний результат:** як очікувалось. **PASS**
