## Слайд 4. Як працює алгоритм

| Характеристика | Коефіцієнт |
|---|---|
| Хобі | 0.45 |
| Вік | 0.25 |
| Професія | 0.20 |
| Стать | 0.10 |

Кожна характеристика — оцінка від 0 до 1:
- хобі: скільки хобі людини збіглось і наскільки подарунок саме про них
- вік: чим ближче до середини вікового діапазону подарунка, тим краще
- професія: збіг → 1, інакше 0.3; стать: підходить → 1

Приклад: Олена, 25, дизайнер, малювання + фотографія →
«Скетчбук і маркери» **89%**, «Графічний планшет» **80%**, «Штатив» **74%**

## Слайд 7. Технології і архітектура

# Сценарій демонстрації (≈ 3 хв)

Підготовка: `npm run dev`, очистити localStorage, відкрити http://localhost:5173.

1. **Додати людину:** Олена, 25, жіноча, дизайнер, бюджет порожній, хобі: малювання, фотографія → «Додати».
2. **Показати перевірку:** ім'я `А`, вік `25.5` → «Додати» → показати червоні помилки → очистити форму.
3. **Підбір:** на картці Олени «🎁 Підібрати подарунок» → показати відсотки, причини, ціни.
4. **Маркетплейс:** натиснути «Rozetka» біля першого подарунка → відкрилась Rozetka → повернутися.
5. **Бюджет:** «← Назад» → «Редагувати» → бюджет `1000` → «Зберегти зміни» → «Підібрати» → «Графічний планшет» (2500 грн) зник.
6. **Додати ще людину:** Андрій, 19, чоловіча, студент, хобі: музика, ігри.
7. **Пошук:** ввести `МУЗИКА` → видно тільки Андрія.
8. **Статистика:** меню «Статистика» → 2 людини, переходи Rozetka: 1.
9. **Тести:** у терміналі `npm test` → 26 passed.
